# Autonomous AI Agent Tool Use

This example demonstrates the core concept of an autonomous AI agent, contrasting it with simple chatbots. It showcases an agent that can interpret a high-level goal, "think" (simulated by a mock LLM) to plan a sequence of actions, and then "act" by executing predefined "tools" to achieve the task, including multi-step operations and passing context between tools.

## Language

`python`

## How to Run

Save the code as `main.py` and run it from your terminal using `python main.py`.
